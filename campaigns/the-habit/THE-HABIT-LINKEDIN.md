## Day 1 — Monday

**Image:** `day-01-named-1080.png`  
**First comment:** “1/7 — The Habit. Tomorrow: the room you go back to.”

### PASTE START

I can tell how serious someone is about AI by whether the model has a name.

Not the vendor's name. A name they said out loud when they loaded it. Tape on a drive. A regular, not a tab they will close.

Chatbots are rented. A named model is a relationship. You come back. You learn its tells. You stop introducing yourself from zero every morning.

I didn't build another chatbot. I built a place for people who already named the thing.

### PASTE END

---

## Day 2 — Tuesday

**Image:** `day-02-room-1080.png`  
**First comment:** “2/7 — A new chat feels clean. It is also how you lose the week.”

### PASTE START

A new chat feels clean. It is also amnesia.

The work I care about lives in a room I return to. Same desk. Same unfinished argument. Same files sitting where I left them at 11:40.

If your AI wipes the table every time you sit down, you don't have a practice. You have a vending machine.

I go back to the same room.

### PASTE END

---

## Day 3 — Wednesday

**Image:** `day-03-no-1080.png`  
**First comment:** “3/7 — The most useful thing in my setup is a rejection I kept.”

### PASTE START

The most useful thing in my setup is not a generation. It's a no I kept.

A no means someone looked. A no means the system waited. A no is how the room learns what I will not ship.

I don't want a tool that is brave with my files. I want one that is patient.

Keep the no.

### PASTE END

---

## Day 4 — Thursday

**Image:** `day-04-building-1080.png`  
**First comment:** “4/7 — There is a machine in this building that does not call home.”

### PASTE START

There is a machine in this building that does not call home.

Not as a slogan. As furniture. It sits under a desk and does the thinking that does not get to leave.

Some work is not a cloud problem. Some work is a room problem.

I wanted the room to be allowed to think.

### PASTE END

---

## Day 5 — Friday

**Image:** `day-05-tool-1080.png`  
**First comment:** “5/7 — I would not ask a plumber to sign the structural drawings.”

### PASTE START

I would not ask a plumber to sign the structural drawings.

I don't know when we decided one chat window was every trade. The work I do has jobs. Jobs have tools. Tools have names.

A specialist is not a prompt you typed in a hurry. It's the person you would actually call at 6pm.

Don't send a generalist.

### PASTE END

---

## Day 6 — Saturday

**Image:** `day-06-argue-1080.png`  
**First comment:** “6/7 — If everyone agrees in the first pass, nobody looked.”

### PASTE START

If everyone agrees in the first pass, nobody looked.

I want the person who will ship it and the person who will refuse it in the same room, interrupting each other. I want to be the one who ends the meeting.

Agreement is cheap. A decision with fingerprints is not.

Let them argue.

### PASTE END

## Posting

1. Native image post. Do not also drop a URL on days 1–6 — LinkedIn will steal the still with a link preview.
2. First comment is the pin line only. No feature glossary underneath.
3. If someone asks what it *is*, answer in the thread like a person: “desktop app I use to run local and cloud models as a team, with a human yes before files move.” Then stop.
4. Day 7 is the only download. If the week worked, people will ask before Sunday.

## Voice

Write like a letter from the desk. Short sentences. No product nouns from the landing page. Attack the *feeling* (amnesia, rental, bravery with files), not a competitor.
