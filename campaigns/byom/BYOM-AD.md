## LinkedIn (longer)

> The model wars sell you a brain. What I wanted was a **room** for many brains — with a repo, an editor, and rules before anything hits disk.
>
> **Neural Junkie** is a local-first **agent IDE**:
> - **Bring your own model** — Ollama, Claude, GPT, LM Studio, Hugging Face, any OpenAI-compatible API
> - **Per-agent routing** — cheap local model for drafts, frontier API for review
> - **Model library** in the toolbar (⇧⌘M) — browse and install like apps
> - **IDE layout** — files, editor, main chat; optional Team layout for channels and collab
> - **You approve file changes** — proposals and diffs, not silent writes
>
> Open source beta (macOS / Windows / Linux): https://github.com/camronwood/neural-junkie/releases/tag/v1.0.0-beta.20
