Thank you, open source

Neural Junkie is a $0 experiment — we could not exist without the maintainers who ship free tools, libraries, and infrastructure. This page names the projects we rely on most and links back so you can star, sponsor, or contribute upstream.

Star Neural Junkie Built for $0

How to give back: star or sponsor a project below, file a good bug report, send a docs PR, or donate to foundations (Rust Foundation, Python Software Foundation, etc.). Full dependency trees live in go.mod, desktop/package.json, and desktop/src-tauri/Cargo.toml.
