IDE v4 — full editor depth, remote workspaces

Open-source agent IDE with full language-server support, remote SSH via the nj-remote sidecar, dev container attach, and optional tree-sitter symbol search — on top of IDE v3 Ask/Agent routing and implementation sessions.

Full Monaco LSP

Persistent gopls, rust-analyzer, and pyright-langserver processes managed by the hub. The desktop connects over WebSocket for hover (and the foundation for completion, go-to-definition, and rename).

Remote SSH

Run nj-remote on your EC2 box or dev machine. Connect from the desktop — file tree, git, LSP, and implementation-session verify steps route through WorkspaceBackend.

Dev containers

Repos with .devcontainer/devcontainer.json get an attach plan from the hub. Run the sidecar inside the container after devcontainer up.

Open source

Neural Junkie is open source. Fork it, run it locally, contribute features — build the IDE you actually own.
