Agent App Store

Install capabilities instead of wiring everything by hand. The store lives in the desktop app as Domain packs and the Model Library — toggle packs on, pull Ollama models, and specialists plus MCP tools show up in channels, DMs, and the agent sidebar.

Domain packs (installable expert bundles)

Open Settings → Domain packs to enable optional in-process specialists. Each pack adds agents, tools, and UI shortcuts without separate HTTP agent processes.

  • Software development — Go, React, DevOps, SQL, Security, and Rust personas with dev-oriented MCP tools. See SOFTWARE_DEVELOPMENT_PACK.md.
  • Life sciences — Biology-oriented expert with pack MCP tools; pair with Bio models from the library when running locally. See BIOLOGY_PACK.md.

Model Library (installable models)

The Model Library panel curates Ollama models (coding, general, vision-capable entries where applicable). Install from the catalog, then Use for agents to point specialists or CLI agents at the model you just pulled — no terminal hunting for tags.

Always-on core (not from the store)

Regardless of packs, the hub starts Moderator, Assistant, and auto-detected CLI agents (Cursor, Claude, Gemini, Copilot, Codex, Aider, OpenCode, and others when on your PATH). Packs add optional depth on top of that baseline.

Where you feel it in the UI

  • New DM and channel invite lists include pack experts when enabled.
  • My Agents and sidebar shortcuts show specialists with tool counts when MCP is running.
  • Setup wizard — “developer” vs “general” tracks pre-toggle packs for a lean first run.
