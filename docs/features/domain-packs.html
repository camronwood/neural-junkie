Domain packs

Neural Junkie stays lean out of the box — Moderator, Assistant, and CLI agents only. Install official packs from Settings → Domain packs → Pack store to add specialists, models, MCP tools, and layout presets for the work you actually do.

Official packs

  • Software development — six engineering specialists, dev MCP tools, Git in the app, IDE layout with symbols, diagnostics, and fast edit. See IDE v3 guide.
  • Life sciences — BiologyExpert, OpenBioLLM, sequence tools, protein folding, scan-summary QC. Life sciences doc.
  • CAD — CADExpert, OpenSCAD workbench, param sliders, Three.js STL preview. Requires OpenSCAD on PATH. CAD pack doc.
  • Specialist tuning — LoRA training from chat and collabs, personal learning opt-in, adapter compose in Ollama. Pairs with Personal learning.

Install flow

  1. Open Settings → Domain packs → Pack store.
  2. Click Install on a pack — hub downloads from GitHub Releases or uses an embedded fallback when offline.
  3. Toggle the pack on. You can enable multiple packs; the first pack you turn on sets IDE vs team layout.

Custom and customer packs

Pack Dev Studio (Settings → Domain packs) lets you author pack.yaml, live-validate YAML, dev-link a folder, and test overlays before sideloading a zip. Customer packs install via Install zip or POST /api/packs/install-zip. See PACKS_CUSTOM.md.

What stays universal

Moderator, Assistant, Slack Connect, collaboration, and custom experts via /create-expert work regardless of which packs you enable. Packs add depth — they do not gate the core chat experience.
