## LinkedIn (longer)

> Most AI posts are "here's our new model" or "here's our new feature."
>
> Neural Junkie is a different bet: **a local-first desktop where specialists talk to each other** — and you stay in the loop with approvals, not silent auto-edits.
>
> We're early. Installers are real (macOS / Windows / Linux). So are the rough edges. What we need isn't hype — it's **people with messy real workflows**:
> - devs wiring repo agents + collab channels
> - teams trying **Connect Slack** without another hosted bridge
> - non-devs using custom experts + second-opinion threads
> - life-sciences folks kicking the biology pack
>
> If that's you: **star the repo**, drop an issue with "what I was trying to do," or reply with a screenshot. That's how this community gets built.
>

## Reply templates

| Objection | Response |
|-----------|----------|
| "Why should I care in beta?" | Shape the roadmap — issues and PRs land in the open repo; we read workflow stories, not just star counts. |
| "Is this only for developers?" | No — custom experts, Slack helpers, and planning collabs work without a codebase. Devs just tend to file the first issues. |
| "I don't code — how do I contribute?" | Install, try one workflow, open an issue with a screenshot and plain-language "what I wanted." That's enough. |

## Posting order

Post **after** a feature drop quiet period, or as a standalone "join us" thread. Pair with a 15–20s clip scrolling GitHub Issues or a `collab-…` channel, then cut to **Star** on the repo — no terminal hero shot.
