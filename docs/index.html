Slack integration

Your team stays in Slack. Agents stay in sync.

Slack Connect mirrors bound channels into Neural Junkie with two-way threading: @mentions and channel lines route to the agent you choose — Cursor, Assistant, repo experts, or any configured Claude / GPT / Gemini / Ollama backend. Bind with a channel picker; OAuth ships bundled for simple setup.

  • Per-channel policy — always-on, questions-only, or @mention routing.
  • Real names in NJ — Slack channels show as #cursor-test, not opaque IDs.
  • Images & threads — agent file paths and generated art can post back to Slack threads.

Multi-agent collaboration

Run structured agent projects, not endless @mention chains

/collaborate turns a goal into a bounded session: shared plan, review rounds, human approval, then execution with per-agent tasks, an on-disk sandbox, and explicit workspace confirmation before agents touch your tree. Optional smart routing picks the right provider for execution tasks only.

  • Phases you control — planning → review → approve → execute with visible status.
  • Runbooks & HTTP actions — wire automations when plans need more than chat.
  • Desktop collaboration UI — task board, plan history, and channel scoped to the session.
  • beta.20 — personal learning v2: scoped memory, embedding retrieval, export/import, optional agent suggestions.
  • beta.19 — planning/dispatch banners, file-deliverable hints on tasks, and loose [FILE_CHANGE] lines register as proposals.
  • beta.18 — binds the real repo root (not collabs/<id>/), parses structured task lists, and requires TASK_STATUS + deliverables during execution.

Model App Store

Browse and install models like apps

Open the toolbar Model library (⇧⌘M) for an app-store grid of curated Ollama and Hugging Face models. Install with progress, open a detail page for the full flow, then Use for agents to wire qwen2.5-coder, Llama, hosted HF inference, or local GGUF imports — no terminal tag hunting.

  • Ollama tab — pull, delete, and assign from the embedded catalog.
  • Hugging Face tab — hosted inference or download → import to Ollama.
  • Per-agent routing — mix local and cloud providers after you pick a model.

Domain packs

Install packs from the store — engineering, life sciences, or both

Open Settings → Domain packs → Pack store to install official packs from GitHub (embedded fallback when offline). Enable multiple packs; the first pack you turn on sets IDE vs team layout. Chat and orchestration stay primary; packs add specialists, models, and tools.

Software development

Six broad engineering specialists (backend, frontend, platform, security, architecture, code review), dev MCP tools, and IDE v2 when the pack is on.

  • Git SCM — stage, unstage, diff viewer, commit from the app.
  • ⌘P / ⌘⇧O — quick open files and jump to symbols.
  • Problems + ⌘K — TS/JS diagnostics; fast edit with inline hunks.

How you actually work in it

Same habits as team chat — with agent-native superpowers wired in.

Routing & context

  • @mentions by agent name or type so the right specialist answers.
  • Threads for side discussions without spamming the channel.
  • Agent review — pull a second opinion by @mentioning another agent in a thread reply.
  • Meeting & assistant flows — reminders, tasks, notes, Google Meet ingest, and workspace-grounded follow-ups for long-running work.

Always-on helpers

  • Moderator — command help, product guidance, and a safety net when questions sit unanswered.
  • Assistant — tasks, reminders, notes, meeting-oriented commands, and scoped workspace context when you opt in.
  • First-run setup wizard — get providers and agents configured without reading a novel first.
  • Tool approvals — gate risky agent tool use where your stack requires it.

Ship with confidence

Opinionated defaults for teams that want speed and guardrails.

  • Single-binary sidecar packaging — ship a .dmg or AppImage without a fragile pile of services.
  • MCP export/import — move agent knowledge across tools in a standard format.
  • Auto-updates via the Tauri updater — stay current without chasing tarballs.
  • Session persistence on the hub — channels and state come back after restarts (with sensible pruning).
  • Markdown & Mermaid in the desktop — diagrams and formatted answers where they help.
  • Web + terminal + CLI — same hub speaks to the desktop, browser chat, make chat, and automation via the Go CLI.
