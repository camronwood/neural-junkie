Download Neural Junkie

Latest beta: 1.2.0-beta.5 July 6, 2026. On macOS, install with Homebrew cask (recommended) or a direct .dmg. On Linux, use Homebrew formula or the .deb below. Windows uses the .msi in the grid, or browse all assets on GitHub. macOS bundles Ollama; Windows and Linux slim builds install Ollama via the setup wizard on first launch. In-app auto-updates on macOS and Windows (beta channel). v1.2.0-beta.5 adds ReAct tools on Gemma, per-turn routing trace, Runbooks v2, multi-repo workspace scope, collab hardening, and LoRA v2 specialists.

Homebrew recommended

Same GitHub Release artifacts as direct downloads — managed installs and upgrades via camronwood/tap.

macOS · cask

Apple Silicon and Intel .dmg. Ollama bundled. Fewer Gatekeeper prompts than a raw download.

brew tap camronwood/tap
brew install --cask neural-junkie

Upgrade: brew upgrade --cask neural-junkie

Linux · formula

Requires Homebrew on Linux. Installs the published .deb binary into the Homebrew prefix — not --cask (casks are macOS-only).

brew tap camronwood/tap
brew install neural-junkie

Upgrade: brew upgrade neural-junkie · Wizard installs Ollama on first launch if needed.
