How we benchmark

Each run uses make model-benchmark against a live hub: switch all agents to one Ollama tag, then execute the same implement + chat scenarios. Some implement scenarios also get an independent LLM deliverable judge (Pass/Fail on quality, not just whether files changed). Results are published with make publish-model-benchmarks.
