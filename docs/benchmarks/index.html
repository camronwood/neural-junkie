How we benchmark

Each run uses make model-benchmark against a live hub: switch all agents to one Ollama tag, then execute the same tracks (implement, chat, optional collab / Arena / CAD). Some implement scenarios also get an independent LLM deliverable judge with a numeric quality score. Reports include tokens, TTFT, and tok/s when the hub records inference usage. HumanEval-25 is an external calibration track only — it does not drive capability routing. Results are published with make publish-model-benchmarks. Full methodology · Raw logs
