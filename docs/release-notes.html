1.0.0 — stable (cut when checklist passes)

First stable release. Same feature set as beta.33 plus fixes on main since beta.33 (DM subscription race, macOS tao patch, conversation scenario expansion). Stable updater channel. macOS: ad-hoc signed at v1.0.0 — Right-click → Open if Gatekeeper warns. Notarization: planned v1.0.1 when Apple Developer credentials are available. Scope: STABLE_SCOPE.md. Cut using STABLE_RELEASE_CHECKLIST.md.

Added (since beta.33)

  • Stable release infrastructure — checklist, scope, cut script, optional notarization CI.
  • Settings → Security — hub security status.
  • make test-conversation-contract — CI-safe conversation + collab wiring gate.
  • Conversation scenarios — 4 chat + 3 collab participation scenarios; 23/23 regression PASS.

Changed (since beta.33)

  • Stable scope — v1.0.0 ad-hoc macOS; notarization in v1.0.1.
  • Beta updater publish — upload-only for updater-beta (immutable release fix).

Fixed (since beta.33)

  • DM subscription race — eager subscribe on DM channel create.
  • macOS tao crash — Cmd+KeyUp SIGABRT patch.

Known limitation

  • macOS ad-hoc signing — macos-adhoc-sign until v1.0.1 notarization.
