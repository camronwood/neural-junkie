# Security Policy

## Reporting a vulnerability

If you discover a security issue in Neural Junkie, please report it responsibly rather than opening a public GitHub issue.

**Preferred:** open a [GitHub Security Advisory](https://github.com/camronwood/neural-junkie/security/advisories/new) (private).

If that is not available, email the maintainer with:

- Description of the issue and impact
- Steps to reproduce
- Affected version or commit
- Suggested fix (if any)

We aim to acknowledge reports within a few business days.

## Documentation

- [docs/SECURITY.md](docs/SECURITY.md) — threat model, auth, approvals, and hub security settings
- [docs/SECURITY_HARDENING.md](docs/SECURITY_HARDENING.md) — deployment hardening checklist

## Supported versions

Security fixes are applied to the current beta line on `main` and the latest tagged release. Older beta tags may not receive backports unless noted in release notes.
