# Sample Application

This sample demonstrates the `HelloWorld()` function implementation in Go.

## Quick Start

1. Build the application:
   ```bash
   go build -o main.core.sample core/sample/main.go
   ```

2. Run the binary:
   ```bash
   ./main.core.sample
   ```

3. Expected output: `Hello, World!`

## Architecture

- `main()` - Entry point that calls `HelloWorld()`
- `HelloWorld()` - Business logic function that prints "Hello, World!"
