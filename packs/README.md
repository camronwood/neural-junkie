See [docs/PACKS.md](../docs/PACKS.md) for install flow and API.

**Install in desktop:** **Settings → Domain packs** (opens the Domain packs modal) → **Pack store** → **Install**.

**Customer / private packs:** sideload zip via the Domain packs modal. See [PACKS_CUSTOM.md](../docs/PACKS_CUSTOM.md).
